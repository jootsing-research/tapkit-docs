Skills are Markdown instructions that an agent loads when it needs them. They follow the open [Agent Skills](https://agentskills.io) standard. TapKit's skills teach an agent how to control an iPhone through TapKit and where to find things in iOS and Apple's apps. The skills' source is [on GitHub](https://github.com/jootsing-research/skills).

The [Claude](/integrations/claude-code) and [Codex](/integrations/codex-cli) plugins include these skills. Install them separately only for other agents.

## Install

```bash
npx skills add jootsing-research/skills
```

Choose your agent when prompted. Skills don't give an agent access to your phone, so connect the agent to the [MCP server](/integrations/mcp) too.

## Available skills

### Core

| Skill | What it teaches |
|---|---|
| `tapkit` | How to use TapKit's tools and coordinates, check each action with a screenshot, and enter text safely. Always install this one. |
| `tapkit-ios-home-navigation` | Finding apps across Home Screen pages, folders, App Library, Spotlight, and Today View |
| `text-editing` | Placing the cursor, selecting, replacing, and deleting text |
| `ios-pickers` | Setting time, date, and duration wheel pickers reliably |

### Apple apps

TapKit has a skill for each of Calendar, Clock, Files, Maps, Messages, Notes, Photos, Reminders, Safari, and Shortcuts, named after the app in lowercase, such as `reminders`. Each one maps the app's screens and where each control is, and the agent reads it when it can't find something.
