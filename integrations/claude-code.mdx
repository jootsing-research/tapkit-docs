The TapKit plugin for Claude Code adds the TapKit MCP server and TapKit's [skills](/integrations/skills).

## Install

Run these in Claude Code:

```
/plugin marketplace add jootsing-research/tapkit-plugins-claude
/plugin install tapkit@tapkit-plugins-claude
/reload-plugins
```

## Sign in

1. Run `/mcp`.
2. Select the TapKit server and choose **Authenticate**.
3. Sign in to TapKit in your browser and click **Allow access**.

If the browser doesn't open, copy the URL Claude Code prints. If the redirect back fails, paste the full URL from the browser's address bar into Claude Code.

## Try it

```
What's on my phone right now?
```

Claude asks for permission the first time it uses each TapKit tool. Choose the "don't ask again" option to allow a tool for the rest of the project, or keep approving actions one at a time.

## Update

```
/plugin marketplace update tapkit-plugins-claude
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude says TapKit isn't connected">
    Run `/mcp` and check the TapKit server's status. If it needs authentication, authenticate again.
  </Accordion>
  <Accordion title="Claude can't find a phone, or the phone is offline">
    Make sure the Mac app is open and signed in, and the phone's tile isn't showing a setup message. Ask Claude to "list my phones" to see what TapKit sees.
  </Accordion>
  <Accordion title="Actions time out">
    Unlock the phone and check that it's still plugged in. If the phone's tile in the Mac app shows a problem, fix that first.
  </Accordion>
</AccordionGroup>
