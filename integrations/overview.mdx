title: Integrations
description: Use TapKit from Claude, Codex, and any MCP client
---

Every integration connects to the same hosted MCP server, `https://mcp.tapkit.ai/mcp`, and signs in with your TapKit account in the browser. The plugins for Claude and Codex also install [skills](/integrations/skills) that teach the agent how to navigate iOS.

<Info>
  All integrations need the [TapKit Mac app](/setup) running with at least one connected, active iPhone.
</Info>
