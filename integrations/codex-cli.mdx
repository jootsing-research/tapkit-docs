The TapKit plugin for Codex adds the TapKit MCP server and TapKit's [skills](/integrations/skills). The plugin's source is [on GitHub](https://github.com/jootsing-research/tapkit-plugins-codex). For more on Codex plugins, see [OpenAI's docs](https://developers.openai.com/codex/plugins).

<Note>
  You need the [Codex CLI](https://developers.openai.com/codex/cli) installed.
</Note>

## Install

1. Add the TapKit marketplace:

   ```bash
   codex plugin marketplace add jootsing-research/tapkit-plugins-codex
   ```

2. Start Codex and open the plugin directory:

   ```bash
   codex
   ```

   ```
   /plugins
   ```

3. Switch to the **Tap Kit Plugins** marketplace, open **Tap Kit**, and select **Install plugin**.

4. Sign in to TapKit in your browser when Codex asks, and click **Allow access**.
