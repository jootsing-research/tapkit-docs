---
title: Type
description: Type text into the focused field
api: POST /phones/{phone_id}/type
---

Type text into the focused field. Tap the field first so the keyboard is showing.

<ParamField path="phone_id" type="string" required>
  The phone's ID, from [List phones](/api-reference/list-phones).
</ParamField>

<ParamField query="async" type="boolean" default="false">
  Return `{"job_id": ...}` immediately instead of waiting for the action. See [Jobs](/api-reference/introduction#jobs).
</ParamField>

## Body

<ParamField body="text" type="string" required>
  The text to type. US-ASCII only, up to 100 characters.
</ParamField>

<Note>
  Emoji, accented letters, and other characters outside US-ASCII can't be typed. Split text longer than 100 characters across several requests.
</Note>

<RequestExample>
```bash cURL
curl -X POST https://api.tapkit.ai/v1/phones/$PHONE_ID/type \
  -H "X-API-Key: $TAPKIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "hello world"}'
```
</RequestExample>
