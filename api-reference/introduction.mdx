The REST API sends touch and keyboard input to your iPhones and reads their screens. It's the same set of actions agents use through [MCP](/integrations/mcp), for code that doesn't go through an agent framework.

## Base URL

```
https://api.tapkit.ai/v1
```

## Authentication

Send an API key in the `X-API-Key` header. Create keys in the [web app](/web-app#api-keys); they start with `tk_`.

```bash
curl https://api.tapkit.ai/v1/phones \
  -H "X-API-Key: $TAPKIT_API_KEY"
```

A key has access to every phone in your organization. Keep it out of source control and client-side code.

## Before you call an action

A phone accepts actions when:

- its Mac app is open and signed in,
- it's connected, unlocked, and set up in the Mac app, and
- it's active on your subscription.

Call [List phones](/api-reference/list-phones) to get phone IDs and check their `connection_status`.

## Coordinates

Coordinates are integer pixels on the phone's screen, measured from the top-left corner. They match the pixels of a [screenshot](/api-reference/screenshot), and the full range is the `width` × `height` reported by [List phones](/api-reference/list-phones).

## Jobs

Every action runs as a job on the phone's Mac. By default a request waits for the job to finish (up to 60 seconds) and returns it:

```json
{
  "id": "5d2c9a0e-7f7b-4c1e-9d1a-2f4b8e0c3a61",
  "status": "completed",
  "result": {},
  "created_at": "2026-09-23T18:30:00Z",
  "completed_at": "2026-09-23T18:30:01Z"
}
```

`status` is `pending`, `running`, `completed`, or `failed`. A failed action still returns HTTP 200, with the reason in `result.error`. An action that doesn't finish in 60 seconds fails with `"error": "TIMEOUT"`.

Add `?async=true` to return immediately with just the job ID, then poll [Get job](/api-reference/get-job):

```json
{ "job_id": "5d2c9a0e-7f7b-4c1e-9d1a-2f4b8e0c3a61" }
```

## Errors

Request errors use HTTP status codes, with details under `detail`:

```json
{
  "detail": {
    "error": "PHONE_NOT_FOUND",
    "message": "Phone not found",
    "context": { "phone_id": "..." }
  }
}
```

| Status | `error` | Meaning |
|---|---|---|
| 401 | `AUTH_REQUIRED` | No `X-API-Key` header |
| 401 | `INVALID_API_KEY` | The key is wrong or revoked |
| 402 | `SUBSCRIPTION_REQUIRED` | Your organization has no active subscription |
| 404 | `PHONE_NOT_FOUND` | No phone with that ID in your organization |
| 409 | `PHONE_INACTIVE` | The phone isn't active on your subscription. Activate it in the [web app](/web-app#phones). |
| 400 | `MAC_APP_NOT_RUNNING` | The phone's Mac app isn't connected |
| 408 | `TIMEOUT` | A screenshot didn't arrive in time |
