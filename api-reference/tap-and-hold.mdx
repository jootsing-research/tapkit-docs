---
title: Tap and Hold
description: Long press a point on the screen
api: POST /phones/{phone_id}/tap-and-hold
---

Press and hold at a point — for context menus, previews, and edit mode on the Home Screen.

<ParamField path="phone_id" type="string" required>
  The phone's ID, from [List phones](/api-reference/list-phones).
</ParamField>

<ParamField query="async" type="boolean" default="false">
  Return `{"job_id": ...}` immediately instead of waiting for the action. See [Jobs](/api-reference/introduction#jobs).
</ParamField>

## Body

<ParamField body="x" type="integer" required>
  Horizontal position in pixels from the left edge.
</ParamField>

<ParamField body="y" type="integer" required>
  Vertical position in pixels from the top edge.
</ParamField>

<ParamField body="duration_ms" type="integer" default="1000">
  How long to hold, in milliseconds.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.tapkit.ai/v1/phones/$PHONE_ID/tap-and-hold \
  -H "X-API-Key: $TAPKIT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"x": 585, "y": 1266, "duration_ms": 1000}'
```
</RequestExample>
