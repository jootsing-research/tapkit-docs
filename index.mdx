TapKit lets AI agents see, tap, and type on real iPhones. Plug an iPhone into a Mac running the TapKit app, and any agent — TapKit's built-in agent, Claude, Codex, or your own code — can operate it through screenshots and touch input, the same way you do.

Nothing is installed on the iPhone. No jailbreak, no developer mode, no simulator.
